Especificación del programa principal

Objetivo:
Permitir al usuario analizar resonancias en columnas de aire cerradas mediante un menú interactivo.


Objetos a crear:
tubo
Objeto de tipo TuboResonante.

historial
Objeto de tipo HistorialResonancias.


Menú:
1. Calcular frecuencia fundamental.
2. Calcular armónico.
3. Mostrar historial.
4. Calcular promedio de frecuencias.
5. Mostrar frecuencia máxima.
0. Salir.


Secuencia de operaciones:
1. Mostrar menú.
2. Solicitar opción.
3. Ejecutar la acción correspondiente.
4. Registrar resultados en el historial.
5. Regresar al menú.
6. Finalizar cuando el usuario seleccione la opción 0.


Condiciones de salida:
El programa termina únicamente cuando el usuario selecciona la opción 0.


Reglas para el agente:
Mantener el menú.
Utilizar las clases especificadas.
No agregar nuevas opciones.
No eliminar validaciones.
No usar interfaces gráficas.
